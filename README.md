# Smart-Resume-Scorer

Deskripsi Project Sistem rekrutmen otomatis berbasis AI yang mengintegrasikan Gmail, Google Sheets, dan Large Language Model (LLM) via Groq API untuk menyaring resume pelamar secara otomatis — mulai dari penerimaan email, analisis dokumen, scoring, hingga pengiriman balasan kelulusan atau penolakan tanpa intervensi manual.

Solusi yang Diterapkan Mengotomatisasi seleksi administrasi yang sebelumnya memakan waktu berjam-jam menjadi proses instan — mengurangi beban kerja HR, menjamin konsistensi penilaian berbasis kriteria terbobot, dan memastikan setiap pelamar mendapat respons profesional secara otomatis.
